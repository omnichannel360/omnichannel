================================================================================
AUTHENTICATION FLOW
================================================================================

1. Client sends request with Authorization header
2. Middleware extracts Bearer token
3. JWT signature verified with JWT_SECRET
4. Token expiration checked (24 hour window)
5. If valid -> proceed to handler
6. If invalid -> return 401 Unauthorized

================================================================================
SETUP INSTRUCTIONS
================================================================================

1. Generate JWT secret:
   openssl rand -base64 32

2. Set environment variable:
   export JWT_SECRET="<generated-secret>"

3. Or add to .env.local:
   JWT_SECRET=<generated-secret>

4. Start development server:
   npm run dev

5. Generate test token and test endpoints

================================================================================
USAGE EXAMPLE
================================================================================

Generate token:
  const token = await generateToken(
    'user-id',
    'user@example.com',
    'user'
  )

Call protected endpoint:
  fetch('/api/alerts', {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  })

Expected response: 200 OK with data
