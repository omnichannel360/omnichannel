QUICK START
================================================================================

1. Install dependencies:
   npm install

2. Set JWT secret:
   cp .env.example .env.local
   JWT_SECRET=$(openssl rand -base64 32)
   echo "JWT_SECRET=$JWT_SECRET" >> .env.local

3. Run tests:
   npm test

4. Build:
   npm run build

5. Deploy to staging:
   git push origin feature/jwt-auth
