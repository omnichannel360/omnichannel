=============================================================================
AUTHENTICATION FLOW
=============================================================================

1. CLIENT REQUESTS TOKEN:
   POST /api/auth
   Body: { "userId": "user123", "email": "user@example.com", "role": "user" }

2. SERVER GENERATES TOKEN:
   Response: { "accessToken": "jwt...", "refreshToken": "jwt...", "expiresIn": 86400 }

3. CLIENT INCLUDES TOKEN:
   Header: Authorization: Bearer <accessToken>

4. SERVER VERIFIES TOKEN:
   - Parses Authorization header
   - Validates JWT signature
   - Checks token not expired
   - Extracts user claims

5. REQUEST PROCEEDS OR RETURNS 401:
   - Valid: Request continues with user context
   - Invalid: Returns 401 Unauthorized

SETUP INSTRUCTIONS
=============================================================================

1. Configure Environment:
   cp dashboard/.env.local.example dashboard/.env.local
   JWT_SECRET=$(openssl rand -base64 32)

2. Install Dependencies:
   cd dashboard && npm install

3. Build:
   npm run build

4. Test:
   npm test

5. Run Development:
   npm run dev

6. Get Token:
   curl -X POST http://localhost:3000/api/auth \
     -H "Content-Type: application/json" \
     -d '{"userId":"test","email":"test@example.com"}'

7. Use Token:
   curl -H "Authorization: Bearer <TOKEN>" http://localhost:3000/api/alerts
