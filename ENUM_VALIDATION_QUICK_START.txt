❌ REJECTED (Invalid values):
  • Different values: "debug", "pending", "completed", etc.
  • Case mismatch: "INFO", "ACTIVE", "TODO"
  • Wrong types: 123, null, undefined, true
  • Objects/Arrays: {status: "todo"}, ["todo"]
  • Whitespace: "active ", " active"
  • Security attacks: SQL injection, NoSQL injection, type coercion
