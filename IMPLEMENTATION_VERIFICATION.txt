   Problem: fs.stat() followed by fs.readdir() with gap
   Solution: withFileLock wraps both operations atomically

🔒 Write-Write Race
   Problem: Two concurrent requests write to same file
   Solution: withFileLock ensures serialized write access

🔒 Read-Write Race  
   Problem: Read operation occurs during concurrent write
   Solution: withFileLock ensures exclusive access per file

🔒 Directory Creation Race
   Problem: Multiple mkdir() calls on same directory
   Solution: atomicMkdir() uses withFileLock for synchronization
