8 CRITICAL VULNERABILITIES (Deployment Blockers)
═══════════════════════════════════════════════════════════════════════════════

[P0] PASSWORD AUTHENTICATION DISABLED
    File:             dashboard/auth.config.ts:297-317
    Issue:            validateUserCredentials() returns null (intentional)
    Impact:           Users cannot authenticate with email + password
    Severity:         🔴 BLOCKS ALL LOGIN
    Fix:              Implement bcrypt.compare() against user password_hash
    Effort:           2-3 hours
    Test:             REQUIRED: test password verification success/failure

[P1] X-USER-ID HEADER SPOOFING
    File:             dashboard/lib/rate-limit-middleware.ts:110-136
    Issue:            User ID extracted from header without auth validation
    Attack:           Attacker sets X-User-Id: victim_id to exhaust victim's quota
    Impact:           User impersonation + rate limit exhaustion + DoS
    Severity:         🔴 CRITICAL SECURITY RISK
    Fix:              Only accept x-authenticated-user-id from auth middleware
    Effort:           1 hour
    Test:             REQUIRED: test header spoofing blocked

[P2] QUERY PARAMETER XSS
    File:             dashboard/lib/validation/index.ts:159-173
    Issue:            Query params validated for schema, not escaped for output
    Attack:           ?q=<img src=x onerror="alert('xss')">
    Impact:           Arbitrary JavaScript execution in user browser
    Severity:         🔴 CRITICAL
    Fix:              Add DOMPurify sanitization for HTML contexts
    Effort:           1-2 hours
    Test:             REQUIRED: test script tag removal

[P3] RATE LIMIT IP FALLBACK DoS
    File:             dashboard/lib/rate-limiter.ts
    Issue:            All anonymous users share "ANONYMOUS" rate limit bucket
    Attack:           Distributed DoS: exhaust shared quota to deny all anon users
    Impact:           System-wide denial of service
    Severity:         🔴 CRITICAL
    Fix:              Create per-IP fingerprint (IP + User-Agent hash)
    Effort:           2-3 hours
    Test:             REQUIRED: test fingerprint uniqueness + DoS prevention

[P4] ERROR MESSAGE SCHEMA DISCLOSURE
    File:             dashboard/lib/error-handling.ts:150-164
    Issue:            Database errors exposed (UNIQUE constraint failed on users.email_idx)
    Impact:           Schema structure revealed to attacker; aids injection attacks
    Severity:         🔴 CRITICAL
    Fix:              Catch DB errors, log server-side, return generic message
    Effort:           2 hours
    Test:             REQUIRED: test no schema in error responses

[P5] SQL INJECTION DETECTION UNUSED
    File:             dashboard/lib/input-validation.ts:252-266
    Issue:            detectSqlInjection() function exists but 0 calls in production
    Impact:           No runtime injection detection
    Severity:         🔴 CRITICAL (if dynamic SQL exists)
    Fix:              Audit all DB queries (verify parameterized); document
    Effort:           1 hour
    Test:             REQUIRED: verify all queries parameterized (Supabase)

[P6] SECURITY LOGGING FAILS SILENTLY
    File:             dashboard/lib/uuid.ts:20 / crypto-utils.ts
    Issue:            Logger initialization wrapped in try-catch; errors swallowed
    Impact:           Crypto failures never logged; monitoring blind
    Severity:         🔴 CRITICAL
    Fix:              Ensure logger fallback always works; never silent failure
    Effort:           1 hour
    Test:             REQUIRED: test logger works in all scenarios

[P7] INSUFFICIENT RATE LIMIT CONFIG
    File:             dashboard/lib/rate-limiter.ts
    Issue:            Default 100 req/min for ALL endpoints (too generous for auth)
    Attack:           Brute force password (if enabled), API scraping
    Impact:           Weak protection against automated attacks
    Severity:         🔴 CRITICAL
    Fix:              Auth: 5 req/min, Search: 30 req/min, API: 100 req/min
    Effort:           1 hour (part of Fix #3)
    Test:             REQUIRED: test per-endpoint limits enforced
