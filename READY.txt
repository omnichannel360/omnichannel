HOW TO GET STARTED
================================================================================

1. INITIALIZE KANBAN DATABASE
   $ hermes kanban init --database kanban.db

2. LOAD GRAPH DATABASE (optional)
   $ hermes gbrain install --version latest
   $ hermes gbrain import --type agents

3. START HERMES GATEWAY
   $ pm2 start hermes-gateway
   $ pm2 logs conductor

4. VERIFY SERVICES
   $ curl http://localhost:3000/api/health
   $ curl http://localhost:3001/api/health

5. OPEN DASHBOARD
   $ Open browser: http://localhost:3001

6. CREATE FIRST TASK
   $ hermes kanban create "Build user authentication" --priority p1 --assignee conductor

7. WATCH AGENTS EXECUTE
   - Dashboard shows live agent activity
   - Kanban board updates in real-time
   - Metrics stream to Prometheus/Grafana
